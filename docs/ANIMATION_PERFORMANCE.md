# 本地动画性能修复（2026-11-17）

360 槽、12 极、每相 12 路的双层方案播放理想磁动势时，原版本每帧触发大线路图所在文档的绘制。相角滑块还会同步读取控件尺寸，产生额外布局。此次修复降低这两部分开销，电气计算和绕组连接算法没有变化。

## 改动

- 线路图滚动区域增加布局、绘制隔离及独立合成，避免被其他面板动画反复重绘；打印模式撤销隔离，保留完整输出。
- 磁动势面板限制布局和绘制范围，仅在可见且播放时保留额外合成层。
- 高频相角控件采用原生 range，避免随每一帧读取控件几何尺寸。保持可访问名称、1° 手动步长、0–360° 范围和操作后暂停。
- 保留离屏/后台暂停计算与减少动态效果适配。

## 浏览器实测

使用本机 Chrome 原生 Performance 面板，生产构建，DevTools 停靠右侧，无 CPU 节流、无截图采集。方案为 360 槽 / 12 极 / 12 路 / 双层 / 自动节距 30 / 全部相，线路追踪关闭，磁动势面板可见且播放。

| 指标 | v16 基线 | 本地修复版 |
| --- | ---: | ---: |
| 录制时长 | 51.135 秒 | 46.160 秒 |
| DevTools Painting | 31,359 ms（61.3%） | 1,478 ms（3.2%） |
| DevTools Rendering | 15,282 ms | 4,010 ms |
| DevTools Scripting | 2,835 ms | 1,598 ms |
| BeginFrame 事件 | 3,073 | 2,770 |
| DroppedFrame 事件 | 978（31.8%） | 0 |
| FireAnimationFrame 事件 | 2,095 | 2,767 |
| DrawFrame 事件 / 秒 | 40.97 | 29.96 |

上述数据支持“绘制开销显著降低，最终样本未记录到 DroppedFrame”，不支持宣称所有设备 60 FPS。DrawFrame、动画回调、显示器实际呈现帧并不可以相互替代；本次 DrawFrame 频率没有提升。DevTools 本身会增加开销，设备与窗口条件也会影响结果。多个 Paint 根事件可能嵌套，不能相加充当总绘制耗时。

本地保留原始 gzip trace 与解析脚本在 `work/winding-types-review/`，不将包含浏览器环境信息的大型诊断文件上传仓库。初次录制时面板移出视野，系统暂停计算，该段不纳入性能比较。
