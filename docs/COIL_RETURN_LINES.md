# 展开图的线圈后端回路

2026-09-12，依据用户提供的 Motor-CAD 展开图，补充线圈下方的后端回路线。

- 默认显示，图下「线圈回路线」可独立开关。与「跨接与引线」「绕向箭头」分别控制，切换回路线不会改变画布尺寸、缩放或接线。
- 每个可见线圈使用本支路颜色，后端回路线宽为 1，选中时为 1.3；原线圈、跨接与引线为 1.7，选中时为 2.7。细回路线表示线圈后端形状，实际串联关系以电气接线视图及网表为准。
- 后端回路按线圈自身的有向节距从回边返回去边，保留单层/双层、负向节距、长节距和同心式可变节距。跨越定子切口的部分按同一周期裁剪，连续展开的相邻周副本也包含这些细线。
- 回路线占据槽底下方的浅折线区域，串联横线整体下移，为箭头和拱桥留出空间。与跨接和引线相遇时，在细线处留断口；回路线相交处使用白色衬线区分。端部箭头沿线路搜索空隙；短线采用 75% 标记，密集交叉处用白色衬底保护箭头，避免整只线圈的端部方向被省略。
- 相别、支路筛选和选中淡化同时应用于回路线。SVG 导出包含当前可见图层和自包含的交叉遮罩；电气网表、线圈计数、CSV、JSON 及绕组系数不增加任何回路短接边。

验证覆盖既有全部方案及 360 槽双层，检查回路线有向连续性、边界裁剪、箭头净空、独立开关、筛选与导出遮罩完整性。原 Motor-CAD 的 18、54、72 槽接线表回归保持通过。另对 18 槽开关状态、54 槽三路、72 槽六路/第六路及全部相展开图进行独立 SVG 渲染检查。尺寸仅用于展开示意，不表示真实端部长度。

## 2026-09-12：窗口适配与端部箭头修复

线性图按自身 viewBox 宽度乘以缩放比例设置像素宽度，修复关闭连续展开后，适配比例超过 100% 时再次溢出的问题。点击适应窗口后，连续展开切换、相别/支路筛选和容器尺寸变化会重新适配；手动缩放或切换视图退出自动适配。新方案仍按原有行为重置视图设置。SVG 导出使用原始 viewBox 尺寸，与屏幕缩放无关。

端部箭头搜索覆盖整段导线，保留方向与所属线圈，不改变线圈、串联跨接或端子几何。相邻箭头中心保持至少 10 图形单位间距；普通标记检查整个字形的线宽净空，拥挤处使用带白色衬底的紧凑标记。空间索引避免大槽数方案反复扫描所有标记。
