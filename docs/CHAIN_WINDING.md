# 2026-11-17 更新：同心式即时切换与单层链式

## 用户可见变化

此前选择“同心式”只修改待生成参数，图形仍是上次生成的叠绕，需要另点“生成绕组”。现在切换绕组形式或层数会立即自动选节距并生成，画布同时标明当前已生成形式和实际节距。校验失败时显示错误和改正建议，不会用上一张图表示新选择。数字参数仍可集中编辑后生成；导入、恢复和预设保留其实际节距。

单层新增“链式 · 单层等节距”及第09个24槽4极节距5示例。选双层时不提供链式；从链式改为双层会切到叠绕并提示。JSON v2、CSV、WebMCP 使用同一模型和校验规则。

## 模型与独立依据

[安徽大学《电机生产工艺实训指导文档 V1.31》](https://www.ahu.edu.cn/_upload/article/files/d2/0d/d5cd1ea84fea8b03ba8e10eecc73/e19ef6f6-dd7e-45c3-ae74-4180807288af.pdf) PDF第6–7页介绍等节距链式和交叉链式，第18页图3-2、表3-4给出YP2-71M1-4的24槽4极链式接线。

本实现从奇数槽出发，配对距离为y的偶数槽，每个物理线圈均为同一个奇数节距。按电势相带确定相别及绕向，再进行串接和等势分路。反向线圈交换去回槽并保留负的实际跨度。该构造独立于叠绕的一般槽位循环匹配，不通过改标签来模拟链式。

普通链式模型限定单层，q = Q/(3P)为1或偶数整数；奇数q>1所需的交叉链式、分数槽特殊链式不包含在本次模型内，返回E_CHAIN_Q。偶数节距返回E_CHAIN_PITCH，双层链式返回E_CHAIN_LAYERS。范围成立后仍须通过完整槽位、三相对称、支路电势与节距组成检查，不意味着任意路数均可用。

参考表推得的U相有向线圈依次为1→6、12→7、13→18、24→19，串联跳线为6→12、7→13、18→24。本测试在UWV空间相序下与资料的A/B/C命名对应；各相圆周顺序允许循环移位，端子起始位置并不强制等于原图。基波系数由这些线圈推算为cos(15°) = 0.9659258263；这是独立解析校验值，不是资料标注或商业软件输出。

部分规格的普通单层叠绕匹配本身会得到链式排列，例如24槽4极节距5，两者可有相同连接。系统不为制造视觉差异而更改真实槽号。同心式则将同组线圈按共同中心嵌套，保留不同实际节距。
