# 绕组工作台 · Winding Studio

输入极数、槽数、每相并联路数和层数，生成绕组位置与电气连接。先完成公开设计资料调研，再建立数据模型与生成器。界面与导出均由同一组有向线圈和电气网表驱动。

## 启动

需要 Node.js >=22.13（推荐支持原生 TypeScript strip 的新版 Node 22）。

```sh
npm ci
npm run dev
```

终端显示的本地地址即工作台。可通过“保存”将当前方案写入本设备；“完整方案”导出独立 JSON 文件，“打开方案”读取后会重新计算与验证。未将设计数据发送给外部服务。

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

## 已实现

- 三相等匝等节距绕组：单层、双层、4/6/8层普通层对，3–360槽，2–240偶数极。
- 整数槽、分数槽、集中式/分布式典型组合；单层匹配与双层线圈电势相带分配。
- 每相并联路数：等电势类别分配后校验槽层唯一占用、匝数、三相电势、支路基波与指定奇次谐波。
- 展开、Y/Δ电气接线、径向、相量视图；相别、支路、层对过滤；缩放、线圈追踪、线路/表格联动。
- 基波与1–25次空间谐波系数；可播放的理想磁动势；明确区分机械角、电气角、相电流峰值。
- 结构化错误代码、原因和改正建议。未找到方案不等于证明物理不可能。
- JSON方案保存恢复、按筛选导出CSV线圈表、当前视图SVG。
- 适配小屏、键盘焦点、可关闭追踪与减少动态效果。
- 可选WebMCP工具，浏览器不支持时不影响普通操作。

## 数学及工程边界

P是极数，p=P/2；y为两个槽号的距离（不把首尾槽计数作为节距）。每个线圈有明确的去/回槽、去/回层、方向、匝数、相别、支路和串联顺序。kw按带符号线圈边电势复数求和并除以总有效边匝数得到。

自动生成器适用于普通三相等匝等节距布局。尚未实现任意多相、特殊不等匝、空槽、混合单/双层、同心式变节距、发卡焊接/换位和生产工艺优化。多层模型为重复的普通层对，不是发卡工艺工具。并联搜索采用等电势类别，不声称找到了所有可能支路分组。默认假定理想对称N/S极场，检查奇次谐波到25阶；实际环流还取决于磁场、阻抗与工艺偏差。

未运行Motor-CAD/Maxwell，也未验证原生工程文件互导。JSON/CSV为本工作台明确字段格式。磁动势为理想槽安匝积分，不是有限元磁密、转矩、温升或实际反电势电压。

“可用性不低于成熟软件”尚未由商业软件场景对照和用户验收证实。该要求保持开放，不能用单元测试代替。
