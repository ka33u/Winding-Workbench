# 绕组工作台 · Winding Studio

输入极数、槽数、每相并联路数和层数，生成绕组位置与电气连接。先完成公开设计资料调研，再建立数据模型与生成器。界面与导出均由同一组有向线圈和电气网表驱动。

已私有发布：[打开绕组工作台](https://winding-studio-zhangyu.imkakku.chatgpt.site)。

## 启动

需要 Node.js >=22.13（推荐支持原生 TypeScript strip 的新版 Node 22）。

```sh
npm ci
npm run dev
```

终端显示的本地地址即工作台。可通过“保存”将当前方案写入本设备；“完整方案”导出独立 JSON 文件，“打开方案”读取后会重新计算与验证。未将设计数据发送给外部服务。

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

## 已实现

- 三相等匝叠绕及同心式线圈组：仅单层、双层，3–360槽，2–240偶数极。层数超出1或2时返回E_RANGE_LAYERS，界面、导入和接口使用相同限制。
- 整数槽、分数槽、集中式/分布式典型组合；单层匹配与双层线圈电势相带分配。
- 叠绕支持自动或手动节距。默认自动从不超过一极距的最大整数向下检查，选首个通过验证的方案；单层仅试奇数，极距不足一槽时试1槽。自动规则不优化谐波、铜耗或端部。预设、导入与恢复保持文件中的实际节距，切换为手动模式。
- 同心式将节距输入解释为最外圈的最大节距，图形、表格及导出保留每只线圈的实际节距。包含24槽4极单层5/7节距预设；采用有界线圈组搜索，未覆盖所有特殊同心式布局。
- 每相并联路数：等电势类别分配后校验槽层唯一占用、匝数、三相电势、支路基波与指定奇次谐波，并要求各支路具有相同的实际节距组成。
- 展开、Y/Δ电气接线、径向、相量视图；相别、支路过滤；缩放、线圈追踪、线路/表格联动。
- 按圆周线圈中心顺序串接；浅顶端部、紧凑引线及可切换的连续展开。两侧浅色是相邻周重复，不增加线圈计数。含18槽4极双层节距4对照预设。
- 并联分路比较就近连续分组与交错分组，优先减少最长跨接，再比较总跨接槽距；54槽24极3路节距2的U相18行与用户参考表一致。支路配色、路号图例和错行端子标签改善高槽数图形阅读。
- 基波与可切换机械/电气阶次的1–240次空间谐波系数、次谐波与相轴序列分解；可播放的理想磁动势；明确区分机械角、电气角、相电流峰值。
- 结构化错误代码、原因和改正建议。未找到方案不等于证明物理不可能。
- JSON v2方案保存恢复，兼容读取旧v1等节距方案；按筛选导出含实际节距及线圈组的CSV线圈表、当前视图SVG。
- 适配小屏、键盘焦点、可关闭追踪与减少动态效果。
- 可选WebMCP工具，浏览器不支持时不影响普通操作。

## 数学及工程边界

P是极数，p=P/2；y为两个槽号的距离（不把首尾槽计数作为节距）。每个线圈有明确的去/回槽、去/回层、方向、匝数、相别、支路和串联顺序。kw按带符号线圈边电势复数求和并除以总有效边匝数得到。

自动生成器适用于普通三相单层和双层等匝叠绕，以及可由连续同相线圈组变换得到的同心式布局。按用户要求，不再考虑超过两层的模型。尚未实现任意多相、特殊不等匝、空槽、混合单/双层、任意指定变节距及特殊整绕式/交叉式布局、发卡焊接/换位和生产工艺优化。并联搜索采用等电势与实际节距类别，不声称找到了所有可能支路分组。默认假定理想对称N/S极场，检查奇次谐波到25阶；实际环流还取决于磁场、阻抗与工艺偏差。

未运行Motor-CAD/Maxwell，也未验证原生工程文件互导。JSON/CSV为本工作台明确字段格式。磁动势为理想槽安匝积分，不是有限元磁密、转矩、温升或实际反电势电压。

“可用性不低于成熟软件”尚未由商业软件场景对照和用户验收证实。该要求保持开放，不能用单元测试代替。
